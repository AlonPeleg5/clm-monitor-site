מדיניות פרטיות - CLM Monitor

בתוקף מ-16.10.2026

1. מי משתמש בכלי

CLM Monitor הוא כלי מחקר אישי. המשתמש היחיד שלו הוא מפעילו, והוא מתחבר לחשבון Google של המפעיל בלבד.

2. אילו נתוני Google הכלי ניגש אליהם

  • https://www.googleapis.com/auth/gmail.send: שליחת מיילים בשם המפעיל, לכתובת הדוח שהמפעיל הגדיר. הכלי אינו קורא, אינו מוחק ואינו סורק דואר.
  • https://www.googleapis.com/auth/drive.file: יצירה ועדכון של גיליון הארכיון שהכלי עצמו יצר. הכלי אינו ניגש לקבצים אחרים ב-Google Drive.

3. כיצד המידע נשמר

  • אסימון ההרשאה (refresh token) נשמר כסוד מוצפן (GitHub Actions encrypted secret) בחשבון של המפעיל, ואינו נשמר בקוד.
  • תוכן הדוחות והארכיון הוא מידע ציבורי (כותרות, תאריכים, קישורים וציטוטים קצרים), שנשמר במאגר פרטי של המפעיל ובגיליון של המפעיל.
  • הכלי אינו אוסף מידע אישי על אנשים אחרים, אינו משתמש בעוגיות, ואינו כולל אנליטיקה.

4. שיתוף נתונים

נתוני Google של המשתמש אינם נמכרים, אינם משותפים עם צד שלישי, ואינם משמשים לפרסום או לאימון מודלים של בינה מלאכותית. השימוש במידע שמתקבל מממשקי Google עומד ב-Google API Services User Data Policy, כולל דרישות ה-Limited Use.

5. ביטול ההרשאה ומחיקה

אפשר לבטל את גישת הכלי בכל עת דרך myaccount.google.com/permissions. לאחר הביטול הכלי לא יוכל לשלוח מיילים או לעדכן את הגיליון. אסימון ההרשאה נמחק מסודות GitHub לפי בקשת המפעיל.

6. יצירת קשר

לשאלות: כתובת התמיכה המוצגת במסך ההרשאה של Google עבור אפליקציה זו.

English - Privacy Policy

Who uses it. CLM Monitor is a personal research tool. Its only user is its operator, and it connects only to the operator's own Google account.

Google data accessed. gmail.send: sends the daily report email to the address the operator configured; it does not read, delete or scan mail. drive.file: creates and updates only the archive spreadsheet created by the tool; it cannot access other Drive files.

Storage. The OAuth refresh token is stored as an encrypted GitHub Actions secret in the operator's account, never in source code. Reports contain public information only (headlines, dates, links, short quotes). No cookies, no analytics, no data about other people.

Sharing. Google user data is not sold, not shared with third parties, and not used for advertising or to train AI models. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revocation. Access can be revoked at any time at myaccount.google.com/permissions.

Contact. The support email shown on this app's Google consent screen.
